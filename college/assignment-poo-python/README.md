# OOP Assignment - Vehicle Management System

This project was developed for the Object-Oriented Programming course and focuses on classes, encapsulation, and instance methods in Python.

## Objective
The script models a `Veiculo` (Vehicle) class with an encapsulated fuel attribute, allowing the user to check status, travel a given distance (consuming fuel proportionally), and refuel through an interactive terminal menu.

## Project Structure
- **poo.py:** Defines the `Veiculo` class and drives two instances (`carro1`, `caminhao1`) through a menu-based loop.

## Tech Stack and Concepts
- Language: Python 3
- OOP: Classes, encapsulation (private attributes with name mangling), instance methods.
- Control Flow: `while True` loop with menu-driven options.

## How to run
1. Run the script: `python poo.py`
2. Choose an option from the menu (1-Status | 2-Viajar | 3-Abastecer | 4-Sair).
3. Follow the prompts to interact with the vehicles.
